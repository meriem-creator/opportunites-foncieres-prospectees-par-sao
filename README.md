## Périmètre et confidentialité
Chaque présentation contient uniquement les données de sa SAO. Le dépôt et les sites publiés sont publics : cette séparation ne constitue pas un contrôle d’accès. La page d’accueil et ce README listent toutes les SAO publiées.

Les intersections ne sont pas recalculées par ce script. Il sépare les résultats du dernier HTML source. Régénérer ce HTML pour actualiser les résultats. Les valeurs de montant BMK, RSK et JNB restent N/D dans les fiches.

Les fonds cartographiques nécessitent Internet. Les liens INJAZ restent soumis aux droits des utilisateurs.
